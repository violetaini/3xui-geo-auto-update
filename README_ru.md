# 3xui Geo Updater

Легкое мультиязычное средство автоматического обновления файлов Geo для **3x-ui**, с выбором источника, планированием обновлений, ведением логов и безопасным перезапуском.
![Предпросмотр главного меню](screenshots/main-menu-preview.png)
Этот инструмент помогает поддерживать файлы правил Geo в актуальном состоянии для серверов на базе 3x-ui, избегая при этом ненужных перезапусков. Он поддерживает несколько источников, гибкое расписание, простое меню командной строки и перезапускает службу **только в том случае, если файлы действительно изменились**.

## Особенности

- Мультиязычный интерфейс
  - Упрощенный китайский (Simplified Chinese)
  - Английский (English)
  - Русский (Russian)
  - Персидский (Persian)
- Выбор языка при первом запуске
- Поддержка нескольких источников правил Geo
- Выбор одного или нескольких источников
- Режимы обновления по расписанию
  - Ежедневно
  - Еженедельно
  - Каждые N дней
  - Пользовательское выражение cron
- Время выполнения по умолчанию: **03:00**
- Перезапуск **x-ui только при фактическом изменении файлов**
- Поддержка логирования
- Встроенная функция удаления
- Быстрые команды:
  - `xgeo`
  - `3xui-geo`

## Поддерживаемые источники

В настоящее время проект поддерживает следующие источники правил Geo:

1. **Loyalsoldier**
   - `geoip.dat`
   - `geosite.dat`

2. **chocolate4u**
   - `geoip_IR.dat`
   - `geosite_IR.dat`

3. **runetfreedom**
   - `geoip_RU.dat`
   - `geosite_RU.dat`

## Как это работает

Программа скачивает последние файлы Geo из настроенных источников, сравнивает их с установленными локальными файлами и заменяет их только в том случае, если содержимое файла изменилось.

Если хотя бы один выбранный файл был обновлен, скрипт перезапускает `x-ui`, чтобы новые данные Geo вступили в силу.

Если изменений нет, **перезапуск не выполняется**.

## Зачем нужен этот проект

В 3x-ui уже есть функция ручного обновления файлов Geo, однако многие пользователи хотят иметь более безопасный и автоматизированный рабочий процесс.

Этот проект добавляет:

- Выполнение по расписанию
- Выбор источника
- Мультиязычное интерактивное управление
- Ведение логов
- Логика перезапуска только при наличии изменений
- Выбор языка при первом запуске
- Более удобный опыт эксплуатации для долгосрочного обслуживания узлов

## Установка

### Быстрая установка

```bash
curl -fsSL -o install-3xui-geo-updater.sh [https://raw.githubusercontent.com/violetaini/3xui-geo-auto-update/main/install-3xui-geo-updater.sh](https://raw.githubusercontent.com/violetaini/3xui-geo-auto-update/main/install-3xui-geo-updater.sh) && chmod +x install-3xui-geo-updater.sh && sudo bash install-3xui-geo-updater.sh
```

### 1. Скачайте скрипт установки

Загрузите скрипт установки на ваш сервер, например:

```bash
curl -O [https://raw.githubusercontent.com/violetaini/3xui-geo-auto-update/main/install-3xui-geo-updater.sh](https://raw.githubusercontent.com/violetaini/3xui-geo-auto-update/main/install-3xui-geo-updater.sh)
```

Или клонируйте репозиторий:

```bash
git clone [https://github.com/violetaini/3xui-geo-auto-update.git](https://github.com/violetaini/3xui-geo-auto-update.git)
cd 3xui-geo-auto-update
```

### 2. Сделайте его исполняемым

```bash
chmod +x install-3xui-geo-updater.sh
```

### 3. Запустите установщик от имени root

```bash
sudo bash install-3xui-geo-updater.sh
```

После установки меню управления запустится автоматически.

### Первый запуск
При первом запуске скрипт попросит вас выбрать язык перед входом в главное меню.
После этого выбранный язык сохраняется и используется автоматически.

## Использование

**Открытие меню управления:**

```bash
xgeo
```

или

```bash
3xui-geo
```

**Ручной запуск проверки обновлений:**
Откройте меню и выберите: `Запустить проверку обновлений сейчас`

**Удаление скрипта:**

```bash
xgeo uninstall
```

Вы также можете удалить скрипт через меню управления.

## Обзор меню

Панель управления поддерживает:

- Настройку или изменение автоматического обновления
- Немедленный запуск проверки обновлений
- Просмотр логов
- Просмотр текущей конфигурации
- Смену языка
- Удаление запланированной задачи
- Удаление скрипта

## Режимы планирования

Поддерживаются следующие режимы расписания:

- **Ежедневно (Daily):** Запускается каждый день в 03:00
- **Еженедельно (Weekly):** Запускается раз в неделю в 03:00 в выбранный день
- **Каждые N дней:** Запускается каждые N дней в 03:00
- **Пользовательский Cron:** Для продвинутых пользователей, желающих полностью контролировать расписание

## Логирование

Файл логов по умолчанию:

```bash
/var/log/3xui-geo-updater.log
```

Просмотр последних 50 строк:

```bash
tail -n 50 /var/log/3xui-geo-updater.log
```

Просмотр логов в реальном времени:

```bash
tail -f /var/log/3xui-geo-updater.log
```

## Установленные компоненты

- `/usr/local/bin/3xui-geo-runner.sh`
- `/usr/local/bin/3xui-geo-manager.sh`
- `/usr/local/bin/3xui-geo-uninstall.sh`
- `/usr/local/bin/xgeo`
- `/usr/local/bin/3xui-geo`

Файл конфигурации:
- `/etc/3xui-geo-updater.conf`

Директория состояния:
- `/var/lib/3xui-geo-updater`

Файл логов:
- `/var/log/3xui-geo-updater.log`

## Безопасность

Проект включает несколько механизмов для обеспечения безопасности:

- Сравнение содержимого файлов перед заменой
- Перезапуск только при фактическом изменении файлов
- Блокировка процесса для предотвращения одновременного выполнения
- Проверка зависимостей перед выполнением
- Выделенный скрипт для корректного удаления
- Напоминание об очистке кэша командной оболочки после удаления

## Примечания по развертыванию

Этот проект предназначен для серверов, на которых `3x-ui` уже установлен и работает корректно.
Он не устанавливает сам `3x-ui`.

Пожалуйста, убедитесь, что:

- Ваша служба x-ui функционирует
- Ваш сервер имеет доступ к настроенным источникам
- Вы понимаете, какие источники Geo вы хотите включить перед настройкой автоматических обновлений
